        ☁️ ซิงค์กับ Google Sheet ยังไม่ได้ตั้งค่า
        📖 วิธีตั้งค่า (ทำครั้งเดียว)
        1. ไปที่ console.cloud.google.com สร้างโปรเจกต์ใหม่ (หรือใช้โปรเจกต์เดิม)
        2. เปิดใช้งาน Google Sheets API
        3. ไปที่ IAM & Admin → Service Accounts → สร้าง Service Account ใหม่ (ตั้งชื่ออะไรก็ได้)
        4. เข้าไปที่ Service Account นั้น → แท็บ Keys → Add Key → Create new key → เลือก JSON แล้วดาวน์โหลดไฟล์
        5. สร้าง Google Sheet เปล่าๆ 1 ชีต แล้ว copy ลิงก์มา
        6. กด Share ชีตนั้น ให้สิทธิ์ Editor กับอีเมลที่อยู่ในไฟล์ JSON (ช่อง client_email ลงท้ายด้วย .iam.gserviceaccount.com)
        7. วางลิงก์ชีต + อัปโหลดไฟล์ JSON ด้านล่างนี้ แล้วกด "⬆️ ซิงค์ขึ้น" ครั้งแรก
